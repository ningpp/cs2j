- [ ] **Step 1: Insert PathHelper code block after FileHelper**

In `src/CSharpToJava.Core/Pipeline/CompatibilityClassGenerator.cs`, after line 1613 (`});` closing the FileHelper result), insert the PathHelper block:

```csharp
        // ── PathHelper ─ Replaces System.IO.Path static methods ──────────────────────
        var pathHelperCode = $@"package {basePackage};

import java.nio.file.*;

/** Replacement for System.IO.Path static methods (generated by CSharpToJava converter). */
public class PathHelper {{
    /** Mirrors Path.IsPathRooted */
    public static boolean isPathRooted(String path) {{
        return path != null && Paths.get(path).isAbsolute();
    }}
    /** Mirrors Path.GetFullPath */
    public static String getFullPath(String path) {{
        return Paths.get(path).toAbsolutePath().normalize().toString();
    }}
    /** Mirrors Path.GetDirectoryName — returns parent directory path, or null if no parent */
    public static String getDirectoryName(String path) {{
        Path p = Paths.get(path).getParent();
        return p != null ? p.toString() : null;
    }}
    /** Mirrors Path.GetFileName */
    public static String getFileName(String path) {{
        Path p = Paths.get(path).getFileName();
        return p != null ? p.toString() : null;
    }}
    /** Mirrors Path.GetFileNameWithoutExtension */
    public static String getFileNameWithoutExtension(String path) {{
        String name = getFileName(path);
        if (name == null) return null;
        int dot = name.lastIndexOf('.');
        return dot > 0 ? name.substring(0, dot) : name;
    }}
}}
";
        results.Add(new ConversionResult
        {
            Success = true,
            GeneratedCode = pathHelperCode,
            FileName = "PathHelper.java",
            Package = basePackage,
            Diagnostics = new List<Context.DiagnosticMessage>()
        });
```

Note: Inside the `$@"..."` verbatim string, `{{` escapes to a literal `{` in the Java output. The `results.Add()` call is regular C# outside the string, so it uses single braces.
